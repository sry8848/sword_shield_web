# 05 工程骨架验收与剩余缺口

## A. 本次交付验收级别

- 文档：完成。各文档之间互相链接，不暗称全部业务已实现。
- 工程文件：完成 Maven reactor、Gateway、Identity、Activity、MySQL Compose、Flyway 迁移与示例端点。
- 静态检查：在生成环境执行 XML 解析、文件结构校验和纯 Java 编译检查。
- Maven 编译与 Spring 实际运行：**未验证（生成环境没有 Maven/Docker/外部依赖下载权限）**。
- 全量 MVP：未交付；仅是架构骨架+最小业务连通示范。

## B. 可在本机执行的初步验收

```powershell
cd backend
mvn -B clean verify
docker compose up -d mysql
# 运行三个模块后
Invoke-RestMethod http://localhost:8080/api/v1/public/events
```

环境有 Maven 后首先要修复所有编译问题，再执行两个服务和 Gateway 的真实联调。不能仅仅因为 Maven 项目能被 IDEA 导入就称其“可运行”。

## C. 完整 MVP 业务验收（待开发）

- [ ] 游客可读取公开大会、场次、嘉宾、会场
- [ ] 用户注册、登录、Token refresh、退出、会话失效
- [ ] 会务运营创建并发布场次，更新受状态约束

## E. 风险记录

1. 旧工程使用 Dubbo RPC，新工程骨架是 REST + 静态 Gateway 路由的最小交付；与旧项目集成要专项评审。
2. 课程数据库要求（SQL Server 或 MySQL）尚不明确；MySQL 脚本不能宣称兼容 SQL Server。
3. JWT 示例使用 HS256 与内存用户，仅用于本地，不可直接上线。
4. 默认租户相关字段/接口不是完整的多租户隔离，使用中应保留 fail-closed 规则并执行攻击测试。
5. 完整 170 功能清单不是本次工程骨架功能清单。
