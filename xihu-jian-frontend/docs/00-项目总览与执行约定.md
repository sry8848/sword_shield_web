# 00 项目总览与执行约定

## 1. 项目目标
建立西湖论剑大会前端工程底座。大会前台和运营后台独立开发、构建和部署，共享跨应用契约与基础设施。

## 2. 适用范围
- 大会前台：游客浏览、参会用户报名和查询个人报名。
- 运营后台：活动维护、报名管理、现场核验和基础统计。
- 共享基础设施包括 HTTP、公共契约类型和通用工具。
- 团队协作：编码、测试、接口、AI Coding 和交付约定。

## 3. 规范等级
| 等级 | 含义 | 处理方式 |
|---|---|---|
| MUST | 强制规则 | 代码评审把关，可自动验证的规则由质量门禁检查 |
| SHOULD | 强烈建议 | 有明确理由时可以例外，并记录原因 |
| MAY | 可选做法 | 根据模块复杂度决定是否采用 |

## 5. 当前骨架范围
两端保留独立启动和构建入口，共享 HTTP 与时间工具，以及基础测试。实际业务按 [项目 MVP 文档](../../docs/mvp.md)分阶段接入。

## 6. 目标与现状

规范描述已确定的目标架构，当前骨架能力与后续实施差距见 [14 的骨架整改项](14-待确认事项.md#前端骨架后续整改)。业务和接口仍按各自的评审状态执行。

## 7. 变更规范
涉及架构、接口、权限、设计 Token 或部署约定的变更，应先讨论并经确认后更新对应主文档。小范围页面实现优先沿用现有规范。
