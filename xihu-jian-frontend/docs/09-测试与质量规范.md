# 09 测试与质量规范

## 1. 测试分层
| 层级 | 工具 | 验证内容 |
|---|---|---|
| 静态检查 | TypeScript / ESLint | 类型和代码规范 |
| 单元测试 | Vitest | 工具函数、状态映射、纯函数 |
| 组件测试 | Vitest + Vue Test Utils | Props、事件和交互 |
| E2E | Playwright | 用户关键流程 |
| 接口验证 | Apifox / OpenAPI | 请求响应和错误场景 |

## 2. MVP 必测流程
1. 游客打开首页和活动列表。
2. 游客查看活动详情。
3. 未登录用户报名时进入登录流程。
4. 登录后提交报名。
5. 用户查询报名和凭证。
6. 运营人员创建并发布活动。
7. 运营人员查看报名列表。
8. 核验员核验有效凭证。
9. 重复核验被拒绝。
10. 报名和到场统计口径正确。

## 3. 页面状态覆盖
检查正常数据、空数据、请求失败、加载中、无权限、重复提交、非法输入和窄屏布局。

## 4. 合并前检查
```bash
pnpm lint
pnpm typecheck
pnpm test
pnpm build
```
关键用户流程改动还应执行 `pnpm test:e2e`。

## 5. 测试数据
测试数据可重复生成；不依赖生产数据；不提交真实个人信息；Mock 覆盖关键状态而不只是成功状态。
