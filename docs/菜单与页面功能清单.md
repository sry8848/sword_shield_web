# 菜单与页面功能清单

本稿以[功能模块清单与微服务划分评审](功能模块清单与微服务划分评审.md)的 170 项功能为范围，描述完整产品原型。文中的页面、按钮和权限是目标设计，当前完成状态和优先级仍查原功能清单。页面分区表示阅读和操作顺序，桌面与移动端可用不同布局承载。

## 一、菜单树与设置理由

大会前台按游客和参会者要完成的任务分组，运营后台按工作人员负责的工作分组。会前、会中、会后会改变首页和工作台的快捷入口。菜单位置保持稳定，用户可以直接进入当前要用的页面。

### 1.1 大会前台

站点名称为「西湖论剑 · 大会门户」。桌面端主导航按下表排列，「我的」作为个人空间入口。大会助手和登录／注册见 1.4。

| 一级菜单  | 二级菜单与页面                                                                                                                          | 存在理由                                                 |
| ----- | -------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------- |
| 首页    | P01 首页，含大会介绍、重要通知、近期活动和快捷入口。                                                                                                     | 让首次来访的人快速了解大会，让回访用户找到当前要办的事。                         |
| 了解大会  | **大会概况**（P01 大会介绍区）了解背景、日期、地点与面向人群；**大会资讯**（P11）看动态和报道；**讲者嘉宾**（P05）看嘉宾及相关场次；**大会数据**（P09）看公开的活动和报名概况。                           | 集中回答「这是什么大会、谁来讲、有什么值得关注」。                            |
| 议程与参会 | **全部场次**（P02）按日期和会场找活动；**会场指南**（P06）查交通、入场口和路线；**限量活动**（P07）查工作坊席位、付费票和周边的开放状态。                                                  | 支持从找场次到确认时间、地点和资格。普通报名在场次详情 P03 完成，限量申请在批次详情 P08 完成。 |
| 展览与成果 | **展商展览**（P10）查企业、产品和交流入口；**大会成果**（P14）查发布单位、成果说明和附件。                                                                             | 有明确企业或成果目标的用户可直接浏览。                                  |
| 观看与回顾 | **直播与回放**（P04）找当前直播和会后回放；**资料下载**（P12）按场次或讲者找 PPT；**图片与视频**（P13）浏览现场媒体。                                                          | 集中承接在线看大会、补看和获取资料的需求。                                |
| 交流与参与 | **参会交流**（P16）预约展商或其他参会者；**热点讨论**（P23）参与专题；**签名墙**（P15）浏览和提交贺词；**打卡与积分**（P18）完成任务；**趣味互动**（P17，含生成大会海报）制作和分享内容；**我要投稿**（P22）提交文章。 | 用户可按想参与的活动选择入口。与具体场次有关的提问、投票和反馈从场次详情及对应观看入口进入 P19。   |
| 我的    | 默认进入 M01 个人概览，下设 1.2 的各组。                                                                                                        | 方便查个人安排、凭证、权益和处理进度。                                  |

### 1.2 个人空间「我的」

| 菜单分组    | 页面与主要事项                                                                                     | 存在理由                            |
| ------- | ------------------------------------------------------------------------------------------- | ------------------------------- |
| 个人概览    | **个人概览**（M01），默认首页，展示待办、近期活动与入场凭证快捷入口。                                                      | 用户可先查看最近需要做的事，再打开对应记录。          |
| 我的参会    | **我的报名**（M02）查普通报名与凭证；**我的订阅**（M03）查关注场次；**我的日程**（M04）查时间安排；**我的席位与候补**（M05）查免费工作坊席位、退席及递补。 | 报名、关注、日程和免费席位共同构成参会安排，各自保留独立状态。 |
| 我的订单与权益 | **我的订单与票券**（M06）查付款、出票和退款；**我的周边**（M07）查领取凭证；**我的积分与奖品**（M10）查余额、记录和领奖。                     | 用户可集中查看已取得或待完成的权益。              |
| 我的互动    | **我的预约**（M08）管理交流邀约；**我的投稿**（M09）查稿件和审核结果。                                                  | 将需要本人跟进的交流和内容贡献放在一起。            |
| 我的服务    | **我的工单**（M11）查客服回复与办理进度。                                                                    | 转人工后有稳定的回访入口，也可由大会助手直接进入。       |
| 账号设置    | **个人资料**（M12）管理头像、昵称和联系方式。                                                                  | 方便用户从固定位置管理账号资料。退出从个人空间的账号操作进入。 |

### 1.3 运营后台

| 一级菜单    | 二级菜单与页面                                                                                                                           | 存在理由                                              |
| ------- | --------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------- |
| 工作台     | **运营概览**（B02），含个人待办、待审核事项、异常提醒和角色快捷任务。                                                                                            | 登录后优先处理当前工作，例如现场核验员可直接打开扫码核验。                     |
| 大会筹备    | **活动与议程管理**（B03）安排及发布场次；**报名管理**（B04）查看名单；**直播配置**（B06）维护直播和回放入口；**限量活动批次**（B07）设置名额及开放规则。                                        | 集中处理开办前准备，也可维护进行中的活动配置。                           |
| 现场执行    | **现场核验**（B05）验活动凭证；**席位与候补**（B08）查占席和递补；**周边履约**（B10）准备及交付实物；**现场互动**（B20）管理提问、投票与反馈；**打卡与奖品**（B28）处理任务和领取。                       | 让现场人员快速找到核验、现场组织和交付工作。筹备期的候补和奖品设置也可从相应批次或工作台直接进入。 |
| 交易与异常处理 | **订单与退款**（B09）查支付、票券和退款；**异常与申诉**（B11）处理活动取消、名额争议和履约问题。                                                                           | 集中处理需要确认交易状态或人工判断的事项。                             |
| 内容与社区   | **资讯管理**（B12）、**展商管理**（B13）、**成果管理**（B14）、**嘉宾资料管理**（B15）、**媒体管理**（B16）、**文件资产**（B17）维护对外内容及素材；**投稿审核**（B18）、**社区治理**（B19）处理用户贡献。 | 对外发布与用户内容在同一组可查，后台子菜单可用「内容发布」「社区与审核」分区显示。         |
| 用户服务    | **工单队列**（B24）处理人工咨询；**知识管理**（B25）维护答案；**问题洞察**（B26）发现高频问题和知识缺口。                                                                   | 支持从接到问题、解决问题到补充知识的连续工作。                           |
| 数据复盘    | **报名与参与**（B21）看报名、核验与线上观看；**渠道转化**（B22）看来源；**参会反馈**（B23）看评价。                                                                      | 按复盘任务提供统计、明细和导出。查看单场观看记录可从 B21 返回 B06。            |
| 系统设置    | **运营账号与权限**（B27）配置角色、操作授权和数据范围。                                                                                                   | 工作人员的授权范围随职责和场次分配变化。                              |

角色与菜单的对应关系是导航示例。授权具体到可访问页面、可执行操作和数据范围。用户兼任多个角色时合并其实际授权，有可访问子项的父级菜单才显示。

| 工作人员       | 典型入口与权限边界                            |
| ---------- | ------------------------------------ |
| 会务运营       | 大会筹备、现场执行和数据复盘中的授权事项。                |
| 现场核验员      | 从工作台或现场执行进入核验，仅核验分配给本人的场次或领取点。       |
| 限量活动运营     | 管理授权的批次、席位与履约事项。需要交易处理时转交交易运营。       |
| 交易运营       | 交易与异常处理，按授权处理订单、退款及申诉。               |
| 内容运营、展商运营  | 内容与社区中的内容发布和素材入口，展商运营按授权范围维护展商。      |
| 社区运营、场次主持人 | 社区运营处理投稿或签名、评论和话题；主持人从现场执行管理分配场次的互动。 |
| 客服、知识编辑    | 用户服务中的工单或知识入口，订单及批次异常按权限查看或转交。       |
| 数据运营       | 数据复盘中的授权报表与导出。                       |
| 系统管理员      | 系统设置，配置角色与数据范围。                      |

### 1.4 入口类型与放置规则

| 入口类型    | 放置与页面示例                                               |
| ------- | ----------------------------------------------------- |
| 全局导航    | 大会前台主导航、后台任务菜单。例如 P02 全部场次、P10 展商展览。                  |
| 业务上下文入口 | 从对应列表或业务页进入。例如 P03 场次详情、P08 限量活动详情。                   |
| 操作流程入口  | 在当前场次内继续操作。例如在 P03 报名，以及从 P03 或 P04 打开本场提问、投票与反馈 P19。 |
| 全局工具    | P20 大会助手采用全站悬浮入口，可带入当前场次、资料或申请上下文。                    |
| 账号入口    | 前台桌面端右上角进入 P21 登录／注册，个人空间提供账号操作。后台独立登录与账号菜单见 B01。     |

## 二、前台页面与操作

每页的「功能」标记原清单编号。全站重复出现的快捷入口会指向原功能对应页面。页号用于在本文件内定位。

### P01 首页

- **使用者**　游客、注册用户。
- **内容与排版**　大会介绍区包含主题、背景、日期、地点和面向人群，由「了解大会 → 大会概况」直达。随后展示重要通知、近期场次与直播，以及资讯、展商、成果与互动快捷入口。登录后显示最近报名，开放时展示限量活动和状态。
- **按钮与去向**　查看大会介绍；打开通知关联的场次或批次 → P03／P08；查看议程 → P02；进入直播 → P04；最近报名卡片 → M02；限量活动 → P07；生成海报 → P17；打开大会助手 → P20。
- **状态与反馈**　会前展示开放时间，会中突出当日场次，会后突出回放与资料。「重要通知」优先展示已有的改期、开播和限量活动提醒，无有效通知时可收起该区。独立公告的编写、置顶与发布范围待确认后再纳入功能清单。
- **功能**　A01、A12。

### P02 全部场次

- **使用者**　游客、注册用户。
- **内容与排版**　按日期浏览的场次列表。场次卡片展示标题、起止时间、分会场、讲者、主题及直播、名额状态。
- **按钮与去向**　按日期、分会场、主题筛选；按时间或热度排序；清空筛选；查看场次 → P03。
- **状态与反馈**　筛选无结果时提示放宽条件。已满场次可看详情。活动改期时展示更新后的时间。
- **功能**　A02–A04、A28。

### P03 场次详情与普通报名

- **使用者**　游客、注册用户。
- **内容与排版**　先看标题、介绍、起止时间、地点、讲者和名额，再看参与方式、关联 PPT 与互动区。并列显示报名、订阅、个人日程、工作坊席位等独立状态。
- **按钮与去向**　查看讲者 → P05；查看路线 → P06；立即报名 → 报名确认与结果；订阅／取消订阅；加入／移出日程；看直播／回放 → P04；查看资料 → P12；进入限量活动 → P08；分享、评论、点赞；进入提问、投票或反馈 → P19。
- **状态与反馈**　报名确认展示场次与报名规则，来源从当前网页或推广链接传递。显示未开放、已截止、已报名、满额、成功及处理中。下线时提示场次不可用，并按身份给出历史报名或公开列表入口。
- **功能**　A05–A06、A09–A11、A21、A25、A29、A37、C21、I01、I04、I06、I10、I12。

### P04 直播与回放

- **使用者**　游客、注册用户。
- **内容与排版**　按正在直播、即将开始、可看回放分组，卡片显示活动名、时间、讲者及观看方式。当前场次的观看入口同时展示该场可用的提问、投票或反馈操作。
- **按钮与去向**　进入直播；观看回放；查看场次 → P03；从当前场次打开提问、投票或反馈 → P19；从回放找资料 → P12。外部直播跳转前也可从当前场次进入互动。
- **状态与反馈**　直播未开始显示时间，回放未发布显示等待提示。登录或票证受限时说明当前可用选项。
- **功能**　A07–A08。

### P05 讲者嘉宾与详情

- **使用者**　游客、注册用户。
- **内容与排版**　列表展示姓名、机构和主题。详情展示介绍、相关场次及直播回放入口。
- **按钮与去向**　按姓名或主题查找；查看相关场次 → P03。
- **状态与反馈**　讲者暂无排期时说明，场次变更后同步更新关联信息。
- **功能**　A33。

### P06 会场指南

- **使用者**　游客、注册用户。
- **内容与排版**　大会地址、交通、入场口、会场图和分会场说明。由场次地点进入时优先展示对应会场。
- **按钮与去向**　查看分会场、查看入口；打开导航；返回场次。
- **状态与反馈**　会场变更显示更新时间。地图加载失败时保留文字地址和楼层。
- **功能**　A31。

### P07 限量活动列表

- **使用者**　游客、注册用户。
- **内容与排版**　按免费工作坊、付费工作坊票、限量周边分组；每条显示场次或规格、时间、资格摘要、当前开放状态。
- **按钮与去向**　按日期、类型、状态筛选；查看活动 → P08；查看已有申请 → M05／M06／M07。
- **状态与反馈**　显示即将开放、开放中、已满、暂停或已结束。没有开放活动时可浏览近期批次。
- **功能**　Q01。

### P08 限量活动详情与抢订结果

- **使用者**　游客浏览，注册用户申请。
- **内容与排版**　标题、场次或规格、设备要求、资格、数量、时间及领取或入场规则。将开放状态、倒计时、资格和申请结果置于主要操作区。
- **按钮与去向**　检查资格及时间冲突；订阅开抢提醒；免费抢席、抢付费票或按规格抢周边；查看本次结果 → M05／M06／M07；满额时加入候补 → M05；需登录时完成登录后返回本批次。
- **状态与反馈**　未开放、暂停、无资格、时间冲突、重复申请、成功、售罄、处理中分别有文案。超时后可查原请求，重复点击指向原结果。确认免费席位后显示查看凭证，付费成功占额后显示继续支付，周边成功后显示领取凭证。
- **功能**　Q04–Q09、Q16、Q20、Q25。

### P09 大会数据

- **使用者**　游客或注册用户，按公开口径展示。
- **内容与排版**　概览展示活动数、报名数、热度和平均报名率；按场次展示报名数、上限和统计时间。
- **按钮与去向**　选择场次或日期；查看对应场次 → P03。
- **状态与反馈**　不限额活动标为「不限额」，报名率显示不适用。仅展示确认可公开的汇总指标，运营明细从 B21 查看。
- **功能**　R01–R02。

### P10 展商展览与展商详情

- **使用者**　游客浏览，注册用户预约。
- **内容与排版**　列表展示展商品牌、标志与简介。详情分企业介绍、产品、视频、关联报道和交流安排。
- **按钮与去向**　按名称或主题找展商；查看产品；打开官网或视频；阅读新闻 → P11；发起预约 → P16。
- **状态与反馈**　缺少视频或产品时隐藏对应入口；可约时段用尽时展示其他场次或返回展商列表。
- **功能**　C08–C11。

### P11 大会资讯与文章详情

- **使用者**　游客、注册用户。
- **内容与排版**　列表展示标题、摘要、分类、发布时间和标签。详情按正文、相关直播／回放、关联媒体和评论区组织。
- **按钮与去向**　关键词搜索、分类与标签筛选；阅读文章；查看关联媒体 → P13；发表／加载评论；点赞／取消；复制分享链接；用文章标题生成分享海报 → P17。
- **状态与反馈**　草稿或下线链接显示不可访问状态。游客可看公开评论，需登录的动作保留文章位置；媒体不可访问时提示原因。
- **功能**　C01–C04、C24、I02–I03、I05、I07–I09、I11。

### P12 嘉宾资料下载

- **使用者**　按发布范围向游客或注册用户开放。
- **内容与排版**　目录展示标题、讲者、关联场次、格式、文件大小及发布时间。来自场次详情时自动筛选。
- **按钮与去向**　按讲者、场次或类型查找；下载文件；复制限时链接；打开相关场次。
- **状态与反馈**　未登录且无权读取时提示登录；链接过期时可重新获取；资料已下线时说明不可下载。
- **功能**　C16–C17、C34。

### P13 图片与视频

- **使用者**　按发布范围向游客或注册用户开放。
- **内容与排版**　媒体列表显示封面、类型、标题和关联报道。预览显示大图或播放器及简介。
- **按钮与去向**　按图片／视频筛选；打开预览、播放或关闭；查看关联文章。
- **状态与反馈**　显示加载、资源不可用、登录后可看和重试入口。

- **状态与反馈**　区分有效、重复核验、场次不符、未到时段、无效、过期和结果待确认。待确认时提示先查原核验记录。

- **使用者**　限量活动运营、现场核验员。
- **内容与排版**　按批次和规格展示可领、已核销、逾期数量及领取点。详情显示凭证和交接记录。
- **按钮与去向**　筛选领取状态；打开凭证核验；确认交接；处理逾期并登记剩余品。
- **状态与反馈**　提示重复领取、凭证过期或规格不符。已核销时显示时间和操作记录。
- **功能**　Q22。

### B11 异常与申诉

- **使用者**　限量活动运营、交易运营、客服。
- **内容与排版**　按误关批次、活动取消、名额争议和履约问题分组。详情展示关联批次、席位或订单与既往处理。
- **按钮与去向**　受理、记录结论；按权限选择保留资格、换场、通知或转退款；关闭事项。
- **状态与反馈**　操作前预览影响范围；存在有效票券或已核验记录时提示先复核，处理后可查看历史。
- **功能**　Q24。

### B12 资讯管理

- **使用者**　内容运营。
- **内容与排版**　列表按草稿、已发布、已下线组织，编辑区含标题、摘要、正文、封面、分类、标签和关联媒体。
- **按钮与去向**　新建、编辑、保存草稿、预览、发布、下线；从文章打开媒体关联 → B16。
- **状态与反馈**　发布前提示缺字段或不可访问的文件；下线时说明旧链接与媒体影响。
- **功能**　C05–C07。

### B13 展商管理

- **使用者**　展商运营、内容运营。
- **内容与排版**　按品牌、状态检索。详情分企业资料、产品、官网与视频、新闻关联、可预约时段。
- **按钮与去向**　新建、编辑、预览、更新展示范围；添加产品、关联新闻；维护可约时段。
- **状态与反馈**　对已发生的预约显示受影响范围，按账号权限限制可编辑的展商。
- **功能**　C12；也是 C13 的运营入口。

### B14 成果管理

- **使用者**　内容运营。
- **内容与排版**　展示成果标题、发布单位、简介、附件和状态。编辑时可对照关联活动。
- **按钮与去向**　新建、编辑、上传或替换附件、预览、发布。
- **状态与反馈**　附件不可用时标出受影响条目；发布前预览公开内容。
- **功能**　C15。

### B15 嘉宾资料管理

- **使用者**　内容运营、获准发布资料的角色。
- **内容与排版**　列表显示标题、讲者、活动、文件类型、大小、可见范围与上下线状态。编辑页先选择文件，再补充资料信息。
- **按钮与去向**　上传、保存到目录、关联场次、预览、发布、下线及调整可见范围。
- **状态与反馈**　区分文件上传成功和目录保存成功；下线时说明旧链接及场次资料入口影响。
- **功能**　C18–C20；也是 C21 的配置入口。

### B16 媒体管理

- **使用者**　内容运营。
- **内容与排版**　媒体列表按图／视频、关联文章和状态筛选。编辑区含文件、类型、标题、说明、封面和关联文章。
- **按钮与去向**　上传媒体；预览、上传或替换封面、选择文章、保存或发布、删除或下架。
- **状态与反馈**　上传失败时保留表单。下架或删除前展示引用文章，并按角色提供操作。
- **功能**　C26–C29、C33。

### B17 文件资产

- **使用者**　内容运营、获准排查文件的管理员。
- **内容与排版**　展示文件名称、对象标识、来源、类型、大小、引用业务和访问范围。
- **按钮与去向**　查引用；上传或查看已上传对象；按业务权限预览或获取限时链接。业务页面仍保留就地上传。
- **状态与反馈**　对象不存在、无权访问、链接过期分别提示。未授权文件不提供下载链接。
- **功能**　C30–C32。

### B18 投稿审核

- **使用者**　社区运营、内容运营。
- **内容与排版**　待审队列按提交时间与状态组织。详情展示稿件、封面、作者与历史处理记录。
- **按钮与去向**　打开待审稿件；审核通过并发布；填写理由并驳回；查看发布结果。
- **状态与反馈**　重复提交或已有其他审核结果时刷新状态。驳回理由同步到本人投稿。
- **功能**　I19–I21。

### B19 社区治理

- **使用者**　社区运营。
- **内容与排版**　签名、评论和话题分组，列表显示来源页面、提交时间、可见状态与审核结果。
- **按钮与去向**　审核签名、隐藏内容；进入原场次或文章；建立、发布或关闭热点话题。
- **状态与反馈**　公开或隐藏后刷新前台可见状态，说明话题关闭对现有讨论的影响。
- **功能**　I15；也是 I25 的运营入口。

### B20 现场互动

- **使用者**　场次主持人、互动运营。
- **内容与排版**　以场次为主，分别展示提问队列、即时投票和会后反馈。队列显示提交时间、得票和处理状态。
- **按钮与去向**　筛选提问、标记已回答；编辑并发布投票、设置收集时间；配置反馈题目并查看回收。
- **状态与反馈**　未开放、收集中和已结束分别显示；关闭收集时说明结果可见范围。
- **功能**　对应 P19 的 I26–I28。

### B21 报名与参与报表

- **使用者**　会务运营、数据运营。
- **内容与排版**　先选日期、场次、渠道与参与方式，再看报名、限额、实际到场、线上观看和分渠道明细。指标显示统计口径和更新时间。
- **按钮与去向**　切换维度、查看场次或报名明细、从单场线上观看数据打开记录 → B06、导出当前筛选报表。
- **状态与反馈**　分别展示 0、尚未采集和无权限。导出按权限控制字段和范围。
- **功能**　R05–R08。

### B22 渠道转化

- **使用者**　数据运营。
- **内容与排版**　显示各来源的访问、报名和转化，附归因时间窗、未识别来源和数据范围。
- **按钮与去向**　按渠道、日期或活动筛选；查看分组明细；导出允许的指标。
- **状态与反馈**　样本不足或部分来源未识别时说明数据覆盖。
- **功能**　R09。

### B23 参会反馈

- **使用者**　数据运营、会务运营。
- **内容与排版**　按场次和问卷版本汇总回收量、评分及匿名意见。
- **按钮与去向**　筛选、查看场次比较、导出汇总。
- **状态与反馈**　未开反馈与无回收分开显示；匿名数据遵循可见范围。
- **功能**　R10。

### B24 工单队列

- **使用者**　客服。
- **内容与排版**　按待受理、处理中、待用户补充、已关闭组织。详情展示用户已同意附带的上下文及关联页面。
- **按钮与去向**　受理、分派、回复、请求补充、转交业务运营、关闭。
- **状态与反馈**　不同角色仅查看授权工单，关闭时记录处理结果，用户在 M11 可查。
- **功能**　S09。

### B25 客服知识管理

- **使用者**　知识编辑、客服主管。
- **内容与排版**　列表按主题、草稿、已发布、下架及生效范围筛选。编辑区含问题、答案、官方来源、适用角色和有效期。
- **按钮与去向**　编辑、预览、审核发布、查看可见范围、下架。
- **状态与反馈**　提示来源过期或链接受限；历史对话可保留原答案版本。
- **功能**　S11–S12。

### B26 客服问题洞察

- **使用者**　客服主管、知识编辑。
- **内容与排版**　按主题统计高频问题、无可靠答案、人工转接及答案反馈。详情展示授权范围内的脱敏样本。
- **按钮与去向**　按日期与主题筛选；查看问题样本；从问题打开或创建知识条目 → B25。
- **状态与反馈**　低样本时标注；个人信息按角色和用途控制展示。
- **功能**　S14。

### B27 运营账号与权限

- **使用者**　系统管理员。
- **内容与排版**　展示运营账号、角色、会场或业务范围、启用状态。详情说明角色能看到的菜单和可执行动作。
- **按钮与去向**　分配或撤销角色；调整数据范围；保存并查看变更结果。
- **状态与反馈**　显示权限变更影响，并限制越权分配。账号失去权限后，对应操作入口及时更新。
- **功能**　U10。

### B28 打卡与奖品

- **使用者**　互动运营、现场核验员。
- **内容与排版**　按任务查看照片打卡与抽奖活动。任务详情展示参与规则、奖品余额、发放和核销记录。
- **按钮与去向**　筹备时可从工作台进入任务和奖品设置，现场可从「现场执行」打开同一页查看打卡、中奖和领取记录；进入现场核销 → B05。
- **状态与反馈**　奖品用尽、待领取、已核销和过期分别展示；更改规则前显示受影响任务。
- **功能**　对应 P18 的 I29／I36、M10 的 I37。

## 五、跨页面的操作规则

| 场景                | 原型中的入口、反馈和去向                                                |
| ----------------- | ----------------------------------------------------------- |
| 游客触发需登录动作         | 在原页面说明为什么需要登录。认证成功后返回同一场次、批次或文章；涉及占额、支付和对外公开时，再由用户确认动作。     |
| 同一场次出现在多处         | 首页和议程负责发现，详情负责执行，「我的」负责查询与后续操作。订阅、加入日程、报名、占席、付款和核验用各自的状态标签。 |
| 列表到详情再返回          | 保留日期、筛选、排序和页码。无记录时说明下一步；筛选无结果时可清除条件；加载失败时可重试。               |
| 会影响资格、内容可见性或交易的操作 | 取消报名、退席、发布／下线、删除、退款、核验前展示对象、影响和确认按钮。操作后显示结果和可查看的记录。         |
| 结果暂时未知            | 报名、抢订、支付和核验保留查原结果入口。明确区分处理中、失败及成功；用户再次打开时可继续查询。             |
| 权限与链接失效           | 公开、登录可见、本人可见和运营权限按数据范围处理。访问受限时说明原因与可用操作。下载链接过期时按原业务权限重新获取。  |
| 响应式排版             | 列表可用表格或卡片，详情可用分区或标签页；移动端优先保留标题、状态和主操作，再展开详细规则和次要字段。         |
