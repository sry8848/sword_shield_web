# 需求 1 · 账号基础数据与初始账号

## 需求

- 前后台共用 MySQL 账号数据。手机号是唯一登录标识，仅支持中国大陆 11 位手机号，由 MySQL 保证全局唯一。密码以 Argon2id 哈希保存，账号状态为 `ENABLED` 或 `DISABLED`。
- 启用的账号具有普通用户身份。后台角色通过账号与角色的关联分配，超级管理员关联 `SUPER_ADMIN` 角色。
- 使用 Spring Boot Profile 区分 `dev`、`test`、`prod`，各自连接独立数据库。Flyway 正式迁移在三个环境执行，测试账号种子数据仅在 `dev` 和 `test` 执行。
- `prod` 的首位超级管理员由项目负责人指定，通过受控 SQL 单独预置账号及其角色关联。真实凭证留在仓库之外。

## 验收

1. `dev` 和 `test` 初始化后，各自的 MySQL 中可查到一个启用的普通测试账号和一个启用的测试超级管理员，前者无后台角色，后者关联 `SUPER_ADMIN`。
2. `prod` 完成 Flyway 正式迁移后，测试账号数量为零。执行受控 SQL 后，可查到启用的首位超级管理员及其 `SUPER_ADMIN` 角色关联。
3. 各环境的初始账号密码均以 Argon2id 哈希保存，插入重复手机号时 MySQL 拒绝写入。
