# 阶段四 · Admin 登录与会话开发计划

阶段四直接基于阶段二账号基线与阶段三 3.1 环境联通成果实施，采用纯 Redis Spring Session（8h 空闲过期、无绝对过期、会话级 Cookie）与 Gateway ForwardAuth，不依赖且不改动阶段三未完的 Portal 3.3/3.4/3.6。[业务设计 v1.5](../../设计/登录设计/登录设计_2026-11-25_16-53.md)、[技术设计](../../设计/登录设计/登录与会话技术设计_2026-11-26_15-42.md)、[OpenAPI](../../../xihu-jian-frontend/openapi/openapi.yaml)

## 1. 锁定参数与范围边界

### 1.1 参数基线

| 决策项 | 锁定行为 |
| --- | --- |
| Session 存储与过期 | Spring Session Data Redis 普通 `RedisSessionRepository`，命名空间 `xihu:admin:session`，仅设空闲过期 `8h`（`28800s`），不设绝对过期。 |
| Cookie 属性 | `admin_session`，`Path=/api/v1`，`HttpOnly=true`，生产 `Secure=true`，`SameSite=Lax`，host-only（省略 `Domain`），会话级 Cookie（省略 `Max-Age`，退出时以 `Max-Age=0` 清除）。 |
| 开发环境与限流 | Admin 本地入口 `http://localhost:5174`（经 Vite `/api` 代理至 Gateway `8080`），可信 `Origin` 默认 `http://localhost:5174`。登录使用独立键前缀 `identity:admin:login:`，沿用手机号 `5 次 / 60s`、来源 IP `30 次 / 60s` 固定窗口。 |

### 1.2 本阶段边界

- **本阶段交付（In Scope）**：增量角色迁移（`EVENT_OPERATOR`、`CHECKIN_STAFF`）及测试种子；Identity Admin 安全链与 `csrf`、`login`、`me`、`logout`、`/internal/admin/session/validate`；Gateway 跨应用 Cookie 双向剥离、Admin 认证直通路由及 `/api/v1/admin/**` 同步 ForwardAuth；下游业务服务（Activity `src/test`）可信身份接收与写请求 CSRF 验证；`@xhlj/shared` RFC 9457 错误对齐与 Admin CSRF/失效扩展；`@xhlj/admin` B01 登录页、首次 `me` 会话恢复、受保护身份壳层、主动退出清理及真实浏览器 E2E 验收。
- **本阶段不做（Out of Scope）**：阶段三 Portal 剩余批次（3.3/3.4/3.6）；B27 运营账号与权限配置页面/接口；B03/B04/B05/B21 真实业务 CRUD 或 Mock 页面；Admin JWT/Refresh、Indexed Session 仓库、MySQL Admin 会话表、Outbox、`localStorage`/`sessionStorage` 持久化、`BroadcastChannel`/`Web Locks`、注册/找回密码/MFA。

## 3. 任务卡

### 4.1 角色迁移与 Identity 会话核心

1. 先编写集成测试覆盖：三类固定角色（`SUPER_ADMIN`、`EVENT_OPERATOR`、`CHECKIN_STAFF`）均可登录；普通账号返回 `403 ADMIN_ACCESS_REVOKED`；未知手机、错密、禁用账号统一返回 `401 UNAUTHENTICATED`；双维限流返回 `429`；登录轮换 Session ID（防会话固定）；写操作与有效会话退出强制校验 `X-CSRF-TOKEN` 和 `Origin`；缺失/过期/匿名 Session 退出免 CSRF 返回 `200` 并清 Cookie；Redis 不可用返回 `503 AUTH_STATE_UNAVAILABLE` 且保留 Cookie；禁用与角色撤销提交后下次 `me` / `validate` 实时生效；Portal 请求不创建或续期 `admin_session`。
2. 新增正式迁移补齐 `EVENT_OPERATOR`、`CHECKIN_STAFF`，新增 `dev/test` 种子账号。
3. 在 Identity 接入 `spring-session-data-redis`、独立 Admin `SecurityFilterChain`、`HttpSessionCsrfTokenRepository` 及各接口实现。

### 4.2 Gateway ForwardAuth 与下游信任边界

1. 先编写网关与跨服务测试覆盖：Portal 路由剥离 `admin_session`、Admin 路由剥离 `portal_refresh_token`；外部访问 `/internal/**` 返回 `404`；伪造 `X-Admin-Account-Id` / `X-Admin-Roles` 或携带 Portal Bearer 均无法通过后台鉴权；经 Gateway 读/写后台受保护接口触发 ForwardAuth 与 CSRF 校验；角色兼任并集生效且 `SUPER_ADMIN` 不自动获得业务角色权限。
2. 实现 Gateway Cookie 剥离、Admin 认证路由与 ForwardAuth 过滤器，并在 Activity 测试源码提供最小受保护读/写处理器，验证打包产物不含测试处理器。

### 4.3 前端 Shared 与 Admin B01 闭环

1. 先编写 Shared 与 Admin 单元测试覆盖：`ApiError` 保留 `title` 并移除 `details`；写请求注入 `X-CSRF-TOKEN`；登录成功重新拉取 CSRF token；`401 UNAUTHENTICATED` 与 `403 ADMIN_ACCESS_REVOKED` 清理会话，普通 `403 FORBIDDEN` 与 `503` 保留会话；退出 `503` 保留状态供重试；退出或切号取消在途私有请求并丢弃迟到旧响应。
2. 更新 `@xhlj/shared`，在 `@xhlj/admin` 安装 `@tanstack/vue-query` 并实现认证 API、Pinia Store、路由守卫、B01 登录页及最小受保护后台身份壳层。

### 4.4 端到端浏览器联调验收

1. 启动真实基础设施与前后端服务，运行 Playwright 用例验证：后台人员登录进入身份页、普通用户登录提示无后台权限、页面刷新恢复身份、主动退出后旧会话不可用、同浏览器双标签页共享 Session 退出后另一页签受保护操作被拦截、同机同时打开 Portal 与 Admin 会话互不串扰。
2. 核对响应 `traceId` 与日志，确保无密码、Cookie 或 CSRF token 泄漏，归档验收结果。
