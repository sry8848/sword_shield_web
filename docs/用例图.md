# 4.2 用例图

根据前面的需求分析和角色划分，系统用例按游客、注册用户和管理员分别组织。游客主要了解大会和浏览公开内容，注册用户参与报名、订阅及互动，管理员负责活动和内容管理。各图中的矩形表示系统边界，人物表示参与者，椭圆表示用例，实线表示参与者与用例之间的关联。

## 4.2.1 游客用例图

游客可以浏览大会与活动介绍、资讯、展商及大会成果，查看图片和视频，并通过活动提供的入口进入直播或回放。需要获取演讲资料时，游客可以查找资料并获取下载链接。决定进一步参与活动后，可以完成注册或登录。

图 4-1 游客用例图

## 4.2.2 注册用户用例图

注册用户能够浏览大会公开内容，并报名参加具体活动、查看自己的报名记录和维护个人资料。订阅活动用于关注感兴趣的活动信息，报名活动用于申请参加活动，两者分别作为独立用例。用户还可以围绕活动或资讯发表评论、点赞和分享，与其他关注大会的人交流。

为便于阅读，游客图中的公开内容访问在本图中以“浏览大会公开内容”概括，个人参与和互动用例分别列出。报名、订阅、个人记录查询及互动操作以用户已登录为前提。

![注册用户用例图](/D:/sword_shield_web/sword_shield_web/汇报图表/用例图/图4-2_注册用户用例图.png)

图 4-2 注册用户用例图

## 4.2.3 管理员用例图

管理员通过管理入口登录后，可以创建活动、修改活动信息、调整发布状态，以及删除活动。内容管理包括发布大会资讯、图片和视频，并预览已发布的媒体内容。管理员还可以查看活动统计，了解报名数量、参与情况和活动热度，为会务安排和运营复盘提供参考。

活动信息维护、发布状态调整和统计查看分别对应不同的管理目标，因此在图中单独列出。各项管理操作均以管理员已登录并具有相应权限为前提。

![管理员用例图](/D:/sword_shield_web/sword_shield_web/汇报图表/用例图/图4-3_管理员用例图.png)

## 4.2.4 用例关系说明

本节通过关联关系说明各角色能够参与哪些用例。活动报名、订阅、评论和分享可以由用户根据需要分别发起，不将这些操作之间的先后关系画成包含或扩展关系。登录要求在相应说明中交代，业务中的判断、分支和操作顺序由核心业务流程图展开。
